# C++ STL – List Reverse Operation

A beginner-friendly C++ STL example demonstrating how to reverse the elements of a List using the `reverse()` function.

## 📌 Function: `reverse()`

The `reverse()` function reverses the order of all elements in a list.

### 🔹 Syntax

```cpp
li.reverse();
```

## 💻 Code Explanation

1. Create a `list<int>` named `li`.
2. Insert 6 elements using `push_back()`.
3. Print the list before reversing.
4. Use `li.reverse()` to reverse the list.
5. Print the list after reversing.

## 📥 Before Reverse

```text
1 → 2 → 3 → 4 → 5 → 6
```

## ⚙️ Operation

```cpp
li.reverse();
```

**What happens?**

- The first element becomes the last element.
- The last element becomes the first element.
- All elements change their positions in reverse order.

## 📤 After Reverse

```text
6 → 5 → 4 → 3 → 2 → 1
```

## 🖥️ Output

```text
Before Reverse: 1 2 3 4 5 6
After Reverse: 6 5 4 3 2 1
```

## 📊 Before vs After Visualization

| Before Reverse | After Reverse |
|:---:|:---:|
| 1 | 6 |
| 2 | 5 |
| 3 | 4 |
| 4 | 3 |
| 5 | 2 |
| 6 | 1 |

## 📚 Concepts Learned

- C++ STL List
- `push_back()`
- `reverse()`
- List traversal using range-based `for` loop
- Before and After comparison

## 🎯 Important Note

- `reverse()` changes the original list.
- It does not create a new list.
- It works directly on the existing list.
- No extra sorting is required.
