# C++ STL – List (Basic Operations)

This program demonstrates the basic operations of the C++ STL List container.

## Topics Covered

- `list<int>` – Declare a list
- `push_back()` – Insert elements at the end
- `for(auto it : li)` – Traverse and print the list
- `front()` – Access the first element
- `back()` – Access the last element

## Output

```text
1 2 3 4
1
4
```

## Concepts Learned

- List declaration
- Inserting elements
- Traversing a list
- Accessing first and last elements
