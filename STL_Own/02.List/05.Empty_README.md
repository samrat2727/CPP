# C++ STL – List Empty Operation

This program demonstrates the `empty()` function of the C++ STL List container.

## Topics Covered

- `list<int>` – Declare a list
- `push_back()` – Insert elements at the end
- `clear()` – Remove all elements
- `empty()` – Check whether the list is empty
- Range-based for loop – Traverse the list

## Operations Performed

1. Insert 6 elements into the list.
2. Remove all elements using `clear()`.
3. Print the list.
4. Check whether the list is empty using `empty()`.
5. Display the result using an if-else statement.

## Output

```text
Empty
```

## Concepts Learned

- List declaration and insertion
- Clearing all elements
- Checking whether a list is empty
- Boolean return values (`true` and `false`)
- Using `if-else` with STL functions
