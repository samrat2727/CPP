# C++ STL – List Remove Operation

A beginner-friendly C++ STL example demonstrating how to use the `remove()` function in a List.

## 📌 Function: `remove()`

The `remove()` function deletes all occurrences of a specific value from a list.

### 🔹 Syntax

```cpp
li.remove(value);
```

## 💻 Code Explanation

1. Create a `list<int>` named `li`.
2. Insert 6 elements using `push_back()`.
3. Print the list before removing.
4. Use `li.remove(3)` to remove the value `3`.
5. Print the list after removing.

## 📥 Before Remove

```text
1 → 2 → 3 → 4 → 5 → 6
```

## ⚙️ Operation

```cpp
li.remove(3);
```

**What happens?**

- Finds the value `3` in the list.
- Removes all occurrences of `3`.
- Keeps all other elements unchanged.

## 📤 After Remove

```text
1 → 2 → 4 → 5 → 6
```

## 🖥️ Output

```text
Before Remove: 1 2 3 4 5 6
After Remove: 1 2 4 5 6
```

## 📚 Concepts Learned

## 🎯 Important Note

`remove()` removes **all occurrences** of the given value, not just the first occurrence.

Example:

```cpp
list<int> li = {1, 2, 3, 2, 4, 2};

li.remove(2);
```

Output:

```text
1 3 4
```
