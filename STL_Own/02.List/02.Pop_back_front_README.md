# C++ STL – List Pop Operations

This program demonstrates how to remove elements from the beginning and end of a C++ STL List.

## Topics Covered

- `push_back()` – Insert elements at the end
- `pop_front()` – Remove the first element
- `pop_back()` – Remove the last element
- Range-based for loop – Traverse and print the list

## Operations Performed

1. Insert 6 elements into the list.
2. Remove the first element using `pop_front()`.
3. Print the updated list.
4. Remove the last element using `pop_back()`.
5. Print the updated list again.
6. Remove the first element again.
7. Print the final list.

## Output

```text
2 3 4 5 6
2 3 4 5
3 4 5
```

## Concepts Learned

- Inserting elements into a list
- Removing elements from the front
- Removing elements from the back
- Traversing a list after modification
