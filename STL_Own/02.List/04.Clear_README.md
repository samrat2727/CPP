# C++ STL – List Clear Operation

This program demonstrates the `clear()` function of the C++ STL List container.

## Topics Covered

- `list<int>` – Declare a list
- `push_back()` – Insert elements at the end
- `size()` – Get the total number of elements
- `clear()` – Remove all elements from the list
- Range-based for loop – Traverse and print the list

## Operations Performed

1. Insert 6 elements into the list.
2. Display all elements before clearing.
3. Display the list size before clearing.
4. Remove all elements using `clear()`.
5. Display the list after clearing.
6. Display the updated list size.

## Output

```text
Before Clear
1 2 3 4 5 6
Size: 6
After Clear

Size: 0
```

## Concepts Learned

- List declaration and insertion
- Traversing a list
- Finding the total number of elements
- Removing all elements using `clear()`
- Checking the list after clearing
