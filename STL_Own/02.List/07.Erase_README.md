# C++ STL – List Erase Operation

This program demonstrates different ways to remove elements from a C++ STL List using the `erase()` function and iterators.

## 📚 Topics Covered

- `list<int>` – Declare a list
- `begin()` – Get the first iterator
- `advance()` – Move the iterator forward
- `erase()` – Remove an element using an iterator
- Single Element Erase
- Position-based Erase
- Range Erase

---

## 1. Single Element Erase

Remove the first element from the list using `erase()`.

**Code:**

```cpp
it = li.begin();
li.erase(it);
```

**Before Erase:**

```text
1  2  3  4  5  6
```

**After Erase:**

```text
   2  3  4  5  6
```

**Output:**

```text
2 3 4 5 6
```

---

## 2. Position-based Erase

Remove an element from a specific position using `advance()` and `erase()`.

**Code:**

```cpp
it = li.begin();
advance(it, 3);
li.erase(it);
```

**Before Erase:**

```text
1  2  3  4  5  6
          ↑
       Iterator
```

**After Erase:**

```text
1  2  3  X  5  6
```

**Output:**

```text
1 2 3 5 6
```

**Explanation:**

- `begin()` starts at the first element.
- `advance(it, 3)` moves the iterator 3 positions forward.
- `erase(it)` removes the element at that position.

---

## 3. Range Erase

Remove multiple elements from a specific range using two iterators.

**Code:**

```cpp
it = li.begin();
it2 = li.begin();

advance(it2, 3);

li.erase(it, it2);
```

**Before Erase:**

```text
1  2  3  4  5  6
↑        ↑
first    last
```

**Visual Representation:**

| Element | Status |
|---|---|
| 1 | ❌ Erase |
| 2 | ❌ Erase |
| 3 | ❌ Erase |
| 4 | ✅ Keep |
| 5 | ✅ Keep |
| 6 | ✅ Keep |

**After Erase:**

```text
X  X  X  4  5  6
```

**Output:**

```text
4 5 6
```

**Important:** `erase(first, last)` removes elements from `first` up to, but not including, `last`.

---

## 4. Comparison of Erase Operations

| Operation | Syntax | Result |
|---|---|---|
| Single Erase | `erase(it)` | Removes one element |
| Position Erase | `advance(it, 3)` + `erase(it)` | Removes a specific element |
| Range Erase | `erase(it, it2)` | Removes a range of elements |

---

## 5. Important Iterator Concepts

| Function | Description |
|---|---|
| `begin()` | Returns iterator to the first element |
| `end()` | Returns iterator to the position after the last element |
| `advance(it, n)` | Moves iterator forward by n positions |
| `erase(it)` | Removes the element at the iterator |
| `erase(first, last)` | Removes elements in the range `[first, last)` |
