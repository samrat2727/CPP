# C++ STL – List Insert Operation

This program demonstrates the `insert()` function of the C++ STL List container.

## Topics Covered

- `push_back()` – Insert elements at the end
- `begin()` – Get the first iterator
- `end()` – Get the position after the last element
- `list<int>::iterator` – Declare an iterator
- `advance()` – Move the iterator forward
- `insert()` – Insert elements at a specific position

## Operations Performed

1. Insert 6 elements into the list.
2. Declare an iterator using `list<int>::iterator`.
3. Initialize the iterator with `li.begin()`.
4. Move the iterator 3 positions forward using `advance(it, 3)`.
5. Insert 4 copies of `5` at the iterator position.
6. Print the updated list.

## Output

```text
1 2 3 5 5 5 5 4 5 6
```

## Important Syntax

```cpp
li.insert(li.begin(), 5);
li.insert(li.end(), 5);
li.insert(it, 4, 5);
```

## Concepts Learned

- List insertion
- Iterator declaration and initialization
- Iterator movement using `advance()`
- Inserting multiple copies of a value
- Inserting elements at a specific position
