# C++ STL – Vector Notes & Practice 🚀

A beginner-friendly collection of C++ STL Vector concepts, examples, and practice problems for Competitive Programming and ICPC preparation.

## 📚 Topics Covered

| No. | Function | Description |
|---|---|---|
| 01 | `push_back()` | Add an element at the end |
| 02 | `v[i]` | Access an element using index |
| 03 | `size()` | Get the number of elements |
| 04 | `front()` | Access the first element |
| 05 | `back()` | Access the last element |
| 06 | `empty()` | Check whether vector is empty |
| 07 | `pop_back()` | Remove the last element |
| 08 | `erase()` | Remove an element or range |
| 09 | `clear()` | Remove all elements |

## 🧠 Quick Revision

### 1. Declaration
```cpp
vector<int> v;
```

### 2. Add Elements
```cpp
v.push_back(10);
v.push_back(20);
```

### 3. Access Elements
```cpp
cout << v[0];
cout << v.at(1);
```

### 4. Get Size
```cpp
cout << v.size();
```

### 5. First & Last Element
```cpp
cout << v.front();
cout << v.back();
```

### 6. Check Empty
```cpp
if (v.empty())
    cout << "Empty";
```

### 7. Remove Last Element
```cpp
v.pop_back();
```

### 8. Erase Single Element
```cpp
v.erase(v.begin() + 1);
```

### 9. Erase Range
```cpp
v.erase(v.begin() + 1, v.end());
```

### 10. Clear Vector
```cpp
v.clear();
```

## ⚡ Important Notes

- Vector indexing starts from `0`.
- `size()` returns the number of elements.
- `end()` points to the position after the last element.
- In `erase(first, last)`, the `last` position is excluded.
- Always check whether a vector is empty before using `front()`, `back()` or `pop_back()`.

## ⏱️ Time Complexity

| Operation | Complexity |
|---|---|
| `push_back()` | O(1) amortized |
| `v[i]` | O(1) |

| `empty()` | O(1) |
| `pop_back()` | O(1) |
| `erase()` | O(n) |
| `clear()` | O(n) |
