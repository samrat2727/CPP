# C++ STL – Vector Sorting

A beginner-friendly C++ STL example demonstrating how to sort vector elements in Ascending and Descending order using the `sort()` function.

## 📚 Concepts Covered

- Vector Declaration
- `push_back()`
- Vector Traversal using `for` loop
- `sort()` Function
- Ascending Order Sorting
- Descending Order Sorting
- `greater<int>()`

## 01. Before Sorting

**Input Vector:**

```cpp
v1 = {100, 20, 300, 5, 10};
```

**Output:**

```text
100 20 300 5 10
```

## 02. Ascending Order (Small to Large)

**Syntax:**

```cpp
sort(v1.begin(), v1.end());
```

**Output:**

```text
5 10 20 100 300
```

## 03. Descending Order (Large to Small)

**Syntax:**

```cpp
sort(v1.begin(), v1.end(), greater<int>());
```

**Output:**

```text
300 100 20 10 5
```

## ⚙️ STL Functions

| Function | Description |
|---|---|
| `push_back(x)` | Adds an element at the end |
| `sort(v.begin(), v.end())` | Sorts in ascending order |
| `sort(v.begin(), v.end(), greater<int>())` | Sorts in descending order |
| `v.begin()` | Returns iterator to the first element |
| `v.end()` | Returns iterator past the last element |
| `v.size()` | Returns the number of elements |

## ⏱️ Time Complexity

| Operation | Complexity |
|---|---|
| Ascending Sort | O(N log N) |
| Descending Sort | O(N log N) |

## 🎯 Learning Goal

Understand how to sort vector elements in both ascending and descending order using the C++ STL `sort()` function.
