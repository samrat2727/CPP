# C++ STL – Vector Reverse

A beginner-friendly C++ STL example demonstrating the use of the `reverse()` function with vectors, both with and without sorting.

## 📚 Concepts Covered

- Vector Declaration
- `push_back()`
- Vector Traversal using `for` loop
- `reverse()` Function
- `sort()` Function
- Reverse Without Sorting
- Reverse After Sorting

## 01. Reverse Without Sorting

**Input Vector:**

```cpp
v1 = {100, 20, 300, 5, 10};
```

**Syntax:**

```cpp
reverse(v1.begin(), v1.end());
```

**Output:**

```text
Before Reverse:
100 20 300 5 10

After Reverse:
10 5 300 20 100
```

## 02. Reverse After Sorting

First, sort the vector in ascending order.

**Step 1: Ascending Order**

```cpp
sort(v1.begin(), v1.end());
```

**Output:**

```text
5 10 20 100 300
```

**Step 2: Reverse the Sorted Vector**

```cpp
reverse(v1.begin(), v1.end());
```

**Final Output:**

```text
300 100 20 10 5
```

## ⚙️ STL Functions

| Function | Description |
|---|---|
| `reverse(v.begin(), v.end())` | Reverses the element order |
| `sort(v.begin(), v.end())` | Sorts in ascending order |
| `push_back(x)` | Adds an element at the end |
| `v.begin()` | Iterator to the first element |
| `v.end()` | Iterator past the last element |
| `v.size()` | Returns the number of elements |

## 🔍 Important Difference

| Operation | Result |
|---|---|
| `reverse()` | Reverses the current order |
| `sort() + reverse()` | Sorts from largest to smallest |

**Remember:** The `reverse()` function does not sort elements. It only reverses their existing order.

## ⏱️ Time Complexity

| Operation | Complexity |
|---|---|
| `reverse()` | O(N) |
| `sort()` | O(N log N) |
| `sort() + reverse()` | O(N log N) |
